常见问题

使用与导出

怎样完成第一次出声？

先准备文稿模型（用于拆书）和语音模型（用于出声）的服务配置。本机模型需先启动服务。

首次导入需要两类当前模型可用、至少一个已启用音色，以及运行中的成声引擎。引擎是应用的处理进程，与模型服务不同。

  1. 配置两类模型

    按所选服务的说明，准备模型 ID、接口地址和所需凭据（如 API 密钥）。安装包不附带模型服务配置。

    在「配置」→「文稿」点「添加模型」，填写服务信息并保存，再点「校验」；需要时点「设为当前」。到「语音」完成同样设置。

    确认：两类模型都通过校验，并显示为当前。

  2. 启用音色，再试听

    支持目录的服务可点「刷新目录」，新音色需手动「启用」。其他服务按页面提示选用音色，或添加音色 ID / 参考音频，再「试听」。

    确认：至少一个音色已启用，且试听成功。

  3. 导入短稿，切章拆句

    回到「书籍」，导入带「第一章」等章题的短 TXT，再点「切章」。规则方式不调用文稿模型，但首次导入仍要求文稿模型可用。

  4. 校样、合成、导出

    为旁白和角色选择音色，未标注的对白先补角色。点「合成本章」，试听后「导出本章」。

导入不可用时，检查两类当前模型、已启用音色和引擎状态。引擎停止时，按应用提示重启；校验或试听失败时，按错误提示检查服务、地址和凭据。

能导出哪些音频？

可导出本章或整书 WAV。整书导出包含有声章节的文件和整书音频；缺句或无声章节会先提示是否跳过。选择跳过后，结果可能不完整。

下载与更新

怎样安装和更新？

打开 DMG，把成声拖入「应用程序」后打开。有新版时，成声会自动下载并核对文件，在「配置」点「重启安装」后生效。

下载失败怎么办？

先查看浏览器下载列表，再重试首屏下载链接；也可用页脚的 ZIP 备用包，解压后将成声放入「应用程序」。检查新版失败不影响当前版本下载。
