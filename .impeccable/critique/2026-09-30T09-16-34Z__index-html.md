## 有效的部分

- 校样是证据，不是假窗口。「示意。改过的那一句单独重跑，整章不用再来。」
- 每个文件说明自己给谁用。D 和 Z 只移动焦点。英雄区里顶栏是线框，到了安装段才是实心。
- 「里面是版本、zip 地址和校验，不是一篇说明。」这句把机器清单说清楚了。

## 优先问题

### [P2] 校验命令不是一行

**为什么重要：** 「在终端粘贴下面这一行」下面，`shasum -a 256` 和文件名各占一行。只粘第一行没有文件。两行一起粘，核的是名字。页面接着说对不上就不要打开。

**改法：** 写成一行 `shasum -a 256 Chengsheng-0.0.7-arm64.zip`，并说明在下载 zip 的文件夹里执行。

**建议命令：** /impeccable clarify

### [P3] 下载确认留在英雄区

**为什么重要：** 从结尾按钮、实心顶栏和手机底栏点下载，确认句子还在英雄区。

**改法：** 顶栏在英雄区状态离开视口后显示短确认。结尾按钮下面放同一句完整确认。手机底栏在点击后显示短确认。

**建议命令：** /impeccable layout

### [P3] 顶栏过早变回线框

**为什么重要：** `.close` 刚碰到视口、按钮只露出 2px 时，顶栏下载就不再是实心。

**改法：** 观察结尾的按钮，而不是整段。

**建议命令：** /impeccable layout
