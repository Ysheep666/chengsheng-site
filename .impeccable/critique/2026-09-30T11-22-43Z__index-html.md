## Design Specificity Verdict

这页是为成声写的，不是通用下载模板。第一屏是一张校样：宋体、衬纸、朱红只给主下载和「已改」。

1440×900：校样底边 507，三句状态解释底边 883，主钮顶 320。390×844：校样 306–619，整张在折线以上，主钮顶 672、宽 342。320 底栏钮 135×44，「下载磁盘映像」一行。三档页面横向溢出都是 0。320 上 `shasum` 那一行 scrollWidth 与 clientWidth 同为 288。

检测器对 index.html 退出码 2，19 条：13 条低对比、5 条贴边、1 条细边加大阴影。屏幕底是 #1c1916。低对比是把屏幕色配到打印用的白底上，屏幕上不成立。真正的打印洞在：常见问题的标题仍是 #f7f4ec（1.10:1），核对 zip 的说明段是 #c8bfb2（1.82:1），核对成功后的状态因为 `data-settled` 权重更高，打印时仍是纸色。校样 1px 边加 48px 阴影是纸边，不当缺陷。404 检测干净。

CSP 挡住了 `http://localhost:8400/detect.js`。标题能改，内联脚本不执行。没有用户能看见的检测叠层。

## Overall Impression

桌面和 390 已经是一张校样加一次下载。320 被最小高度撑成一张空海报，这一项把版面分打到 2。

## What's Working

校样本身就是证据。1440 第一屏能看完四句，朱红只在「已改」和主钮上，角上写着示意。

两种包各有一句后果和真实文件名。核对完成后，不点下载也能看见「已核对，安装包是 0.0.7。」

D 聚焦磁盘映像，Z 聚焦 zip，地址不变。关掉按键之后 D 不再移动焦点。390 和 320 的提示是 `display: none`，D / Z 也不抢焦点。

## Priority Issues

**[P2] 320 第一屏是一块空白**
版本行在 370，底栏在 634，示意稿在 795。`.lead` 的 `min-height: calc(100svh - 5.5rem)` 把稿和两个选择都推到下一屏，而 5.5rem 不够一个 131px 的折行顶栏。
去掉这道最小高度，让稿从这一屏开始，底栏留着。
Suggested command: /impeccable layout

**[P2] Tab 到顶栏下载钮会把页面拉走**
停在安装节、scrollY 1222 时，顶栏钮已经在屏上。从「问题」Tab 过去，焦点对了，scrollY 却变成 762。
钮已经在视口里时，记下 Tab 之前的 scrollY，焦点落下后拨回去。
Suggested command: /impeccable harden

**[P3] 底栏盖住「留在这台电脑上」的第一句**
390 上把更新说明滚到顶，底栏高 66，盖住那句事实 66px。它没有盖住版本行，也没有盖住安装第三步。
读到这一节时把底栏收起。
Suggested command: /impeccable adapt

**[P3] 没脚本时快捷键说明是假的**
不加载 site.js，两个钮仍指向印好的 0.0.7，状态仍是「这一版可以直接下载。」提示却还在，D 什么也不做。
提示默认隐藏，监听接上以后再显示。
Suggested command: /impeccable harden
