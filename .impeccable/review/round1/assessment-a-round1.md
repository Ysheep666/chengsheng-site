# material_fixes

没有 P0；没有发现整页结构或核心机制需要 rebuild，当前证据也不需要 recapture。以下是按影响排序的 5 个 UI 实质问题，外加 1 个 finish 记录问题。

**F1 — P1，首次配置帮助没有兑现。** UI：`index.html:123` 的“了解模型配置”链接打开 `#model-help`；`index.html:153` 安装第三步和 `index.html:177` FAQ 只说去配置模型、准备音色。影响：新访客能下载，却无法判断接下来需要准备什么和怎样得到第一句；容易把“设置模型”理解为应用已经备齐模型，或在此处求助／放弃。修法：连接一份从当前应用与官方文档核实的“第一次出声”指南；明确语音模型与音色需要分别准备、文稿模型什么时候可省略，给出实际配置入口、保存／验证步骤和导入 TXT 的下一步。在安装第三步直接放此入口；若正文不承载全部步骤，则打开同页简短 quick start 并链接完整指南，不虚构支持的提供商或能力。证据：`a-model-help-desktop.png` 与 `index.html:177`。

**F2 — P1，复制失败的恢复内容离开了用户视野。** UI：`site.js:154` 所有复制动作写入共用 `#copy-status`，该节点位于 ZIP disclosure 之后 (`index.html:168`)。影响：尤其在不支持运行的手机上，“复制下载地址”是把安装信息带回 Mac 的实用路径；剪贴板不可用时按钮附近没有成功或失败确认，手动复制值也在下方，用户会反复点击或以为已复制。独立复现中，ZIP 保持关闭；桌面按钮在 y480，失败内容从 y920 开始（900 高视口），手机按钮在 y444，失败内容从 y953 开始（844 高视口）。扩大 ZIP 后距离更长。修法：让每个复制动作拥有邻接的 live status；成功在按钮显示“已复制”，失败在相邻区域展开可选／只读地址或命令，保留可见的手动复制提示与焦点。不要只写页底共用消息。证据：`a-copy-inline-missing-desktop.png`、`a-copy-inline-missing-mobile.png`、`assessment-a-confirm-evidence.json`。

**F3 — P2，手机关键操作和说明被压得过小，次级触控目标不足。** UI：390 宽时 demo 角色／状态 10px、免责声明 10px、操作和反馈 11px；安装说明 12px、下载提示 11px、代码 11px。顶栏安装按钮 40px 高、芯片 disclosure 40px、复制命令／校验值 36px；虽满足较宽松的 24px 底线，但没有达到手机 44px 的舒适目标。影响：访客需要细看或放大才能区分“操作示意”与真实输出、读出下一步；小复制目标易误触。修法：手机上将关键说明和状态提升到 13–14px，安装正文到 14–16px，代码至少 12–13px；辅助命令和芯片控件至少 44px 高。减少侧栏／表头密度或允许换行承担空间，别继续缩字。证据：`a-demo-mobile.png`、`a-install-mobile.png`、`a-checksum-mobile.png` 和 `assessment-a-browser-evidence.json` 的 mobileSizes。

**F4 — P2，返修和重置后键盘焦点丢失。** UI：`site.js:240` 在开始返修时禁用输入，完成的 `site.js:249` 回调只重新启用；`resetDemo()` 也可能禁用当前焦点按钮，没有恢复目的地。影响：Ctrl / ⌘ + Enter 后 activeElement 为 BODY，完成仍为 BODY。按 Tab 走到“改一句试试”，连续编辑自己刚写的句子需要额外逆向导航；焦点可见性与操作的结束位置不连续。修法：保留输入的焦点（例如 readonly 代替 disabled），或在完成／重置时把焦点恢复到第三句输入；只在用户仍处于该操作或焦点落到 body 时恢复，避免用户离开后被抢回。证据：`assessment-a-browser-evidence.json` 的 rendering / completed / reset / firstTabAfterComplete。

**F5 — P2，手机允许编辑的长句无法完整校样。** UI：`index.html:97` 允许 56 字符，但采用单行 input；390 宽时 clientWidth 190px，示例长句 scrollWidth 464px。影响：用户改完或离开输入后只能看到一段内容，没有省略提示也没有全句预览；点击“演示单句返修”之前不能同时核对自己这一整句。它不造成文档横向溢出，却影响“校样”的核心读写任务。修法：将第三句改为自动增长的 textarea，或在失焦时以可换行的完整文本展示；保持状态和返修动作贴近此句，保留清楚长度提示。证据：`a-long-input-stable-mobile.png`、`assessment-a-confirm-evidence.json` 的 mobileLong。
