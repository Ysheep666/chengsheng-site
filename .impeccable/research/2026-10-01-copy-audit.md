## 判断方法与覆盖范围

每条文案检查三个问题：它是否帮助访客判断适用性、完成动作或从失败中恢复；承诺及按钮名是否符合真实发布版本；第一次使用的人能否理解、知道下一步且不被指责。品牌标题可以传达产品身份，但不在每个区段重复收益口号。键盘跳转、字段标签和状态说明属于必要信息，不能为减少字数删掉。

覆盖首页、404、标题/SEO/分享说明、读屏标签、无脚本状态和 JavaScript 全部中文反馈，包括加载、失败、超时、重试、版本变化、下载、编辑、空句、演示和重置。详见 [逐项清单](references/copy-review-inventory.json)：252 个原始源码片段与179个最终片段均有处理结论及三项判断。**片段不是独立文案数量**，包含响应式重复入口、被标签拆开的句子和隐藏发行数据；不把这个数量当成可见文案或删字效果指标。

## 文案决策

| 位置或文案 | 是否必要、处理方式 | 准确性与用户友好依据 |
| --- | --- | --- |
| 页面标题与搜索说明 | 保留成声、TXT、有声书、逐句返修和平台信息 | 描述工具用途与最低系统，不编造效果、价格、用户数或评价。分享摘要只解释单句返修。 |
| 品牌、主导航、跳到正文 | 保留品牌，导航统一为「制书流程」「书稿与模型」「常见问题」 | 名称对应目标内容；手机用「导航」。读屏首页名称和键盘跳转保留。 |
| 「让你的书稿，一句句成声。」 | 保留一次 | 表达产品身份；正文随后具体说明 TXT、角色和校样，避免只给空泛口号。 |
| 首屏产品描述 | 合并为制作结果与单句返修两句 | 「改完一句，只重新合成这一句」说明最小返修单位，没有整章重做承诺冲突。 |
| 下载主行动 | 首屏与顶栏都直接下载；不再跳到重复下载区 | 「下载 Mac 版」对应 DMG 实际链接，不把一次点击描述为完成下载或安装。 |
| 芯片、系统、版本 | 只保留在首屏下载旁的摘要 | Apple 芯片 Mac、macOS 12及以上、当前版本均有发行依据；不通过 UA 猜测 Intel/Apple 芯片或系统版本。 |
| 非 Mac 提示 | 改为「可保存安装包，在符合上方要求的 Mac 上运行成声。」 | 解释保存与运行的区别，保持中性辅助色。两处 DMG 名称改为「保存 Mac 安装包」，三个包链接都关联平台说明。 |
| 首次模型配置前提 | 从后面的流程区移到下载旁；只保留一处，详细步骤折叠 | 使用「首次使用需配置文稿与语音模型」及44px「配置指南」直达入口；避免下载之后才发现重要门槛。 |
| 新版检查状态 | 仅等待、异常、变更时显示；同版本成功保持安静 | 用「检查新版」解释用户任务，去掉「清单已核对」等实现语言。失败明确仍能下载当前版，并给重试。 |
| 点击下载后的反馈 | 「已打开 DMG/ZIP 下载链接。进度请查看浏览器下载列表。」 | 网站不能知道大文件已下载完成。ZIP 在页脚就近播报，版本变化也回到最近点击位置；合法结果返回时清除首屏旧 loading。 |
| 「试改一句」与示例工具栏 | 入口用实际动作；一进入示例就看到「示例 · 不生成音频」 | 不把网页状态演示写成在线语音生成；书名、章节、人物、已出声等均处于明确的示例上下文。 |
| 四句小说、角色、章节 | 保留一份短稿证明返修机制，删除章节下重复口号 | 三句不变，第三句可改。第二章是「示意章节」，不会给不可操作背景假按钮语义。 |
| 校样表头与字段标签 | 保留并补全原生表格行/列关联；窄屏仅视觉隐藏状态表头 | 行号、角色、校样文字、状态可以被读屏识别。第三句有字段名称、56字符上限、计数与当前状态描述。 |
| 「换个例句」「演示返修」「重置示例」 | 名称对应实际行为 | 预设例句不冒充自行编辑；演示按钮不声称生成音频；重置能取消等待并恢复原句。 |
| 示例动态反馈 | 每个状态只交代当前情况或下一步 | 空句提示先填写；已改提示点击演示；完成只说第三句演示结束、其余句子未变。手机不显示桌面快捷键，键盘功能保留。 |
| 示例图注与无脚本说明 | 保留简短边界说明 | 「操作示意，网页不生成音频」是必要澄清；无脚本时说启用 JavaScript 可操作、下载不受影响。 |
| 四步制书流程 | 删除介绍口号和每步附加口号，保留四个动作及一句解释 | TXT导入、规则/模型切章拆句、配声、按句返修、导出均符合实际；导出写「本章或整书」，不制造独立「分章」入口。 |
| 本机与模型说明 | 删除重复宣传与下载 CTA，保留三条不同事实 | 分别回答工程续做、原文/密钥去向、远程文本传输。工程在本机不等同完全离线，本机模型也需准备并启动服务。 |
| 首次出声指南 | 保留在一项 FAQ 内，材料与操作分段，增加两个完成检查 | 两类当前模型、已启用音色和运行中引擎是实际导入条件；解释模型用途及引擎含义，不推荐未经验证的服务。 |
| 音色准备分支 | 依据所选服务能力描述，不一律写成「添加 ID」 | 支持目录可刷新并启用；其他服务按界面选音色或添加 ID/参考音频；确认至少一个启用且试听成功。 |
| 导出 FAQ | 保留 WAV、章节/整书与跳过缺句的结果 | 整书导出包含有声章节及整书音频；选择跳过缺句/无声章可能导致结果不完整，不能暗示一定导出全部章节。 |
| 安装与更新 FAQ | 大安装区移除后只保留折叠内的短交接句 | DMG拖入「应用程序」；真实更新是自动下载核对后，在配置点击「重启安装」生效。没有恢复教程区。 |
| 下载失败 FAQ | 给浏览器列表、重试当前链接、ZIP备用三条恢复路径 | ZIP解压后放入「应用程序」；检查新版失败不阻断已有链接，不保证备用包一定成功。 |
| FAQ 数量和分组 | 合并/删除已在前面回答的平台、隐私、整章返修问题，最终4项 | 「使用与导出」「下载与更新」各两项，问题按任务组织；细节按需展开。 |
| 页脚 | 删除标语，保留 ZIP备用包、版本记录、回到顶部 | 使用短链接提供补充格式与出口，不再新增下载面板。ZIP仍关联运行要求。 |
| 404 | 删除重复首页入口及标语，保留一个返回首页和版本记录出口 | 「页面不存在。」「页面可能已移动，或地址有误。」语气中性，不断言错误由用户造成。 |
| 隐藏发行元数据 | 文件名、SHA-256、发行说明隐藏保留，删除对应可见工具与脚本 | 这是已有发布协议，不是用户文案。仍由实际发布函数更新所有版本与包链接；发行说明删除「打开就能用」的不准确暗示。 |

## 固定发行版本核实

产品事实只读取成声应用仓库的 `v0.0.7`，commit `14c01c3bb3b526d460ac331eb9d8d18595581b17`，通过 `git show v0.0.7:<path>` 获取；不把邻居工作区未提交改动当作发行能力。

| 事实 | 固定标签源码位置 |
| --- | --- |
| macOS最低版本12 | `scripts/pack/bundle.py` 的 `LSMinimumSystemVersion` |
| 首次导入要求两类当前可用模型、启用音色及引擎 | `app/shell/src/nav/mod.rs` 的 `import_gate` |
| 规则切章/拆句不调用文稿模型，不能推导首次导入免配置 | 拆书处理逻辑与 README，和 `import_gate` 分开核对 |
| 添加/保存/校验/设为当前等按钮与音色能力分支 | `app/shell/src/settings/page/`，包括 catalog、voice toolbar、配置持久化逻辑 |
| 新目录音色初始停用；已有音轨修改后标为已改 | 配置持久化与 `app/shell/src/library/` 校样逻辑 |
| 原文只读，密钥在本机配置而非书稿 | 配置持久化与书稿文件/校样保存逻辑 |
| 章/整书WAV及缺句、无声章确认跳过 | `app/shell/src/galley/export.rs`、引擎导出实现 |
| 自动检查、下载核对，用户重启安装后生效 | `app/shell/src/update/mod.rs` |
| DMG拖入应用程序 | `scripts/pack/dmg.py` 中 `/Applications` 链接 |

表格语义按照 [W3C Table Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/table/) 采用原生表格与行/列头，保留单独的编辑控件；窄屏调整视觉位置仍保留逻辑列。浏览器可访问树确认不能代替真实 VoiceOver 验收。

## 审查、修复与验证
